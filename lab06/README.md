# Лабораторная работа 6. Списки и обработка наборов данных
## Задание 1. Статистика
Файл: `statistics.py`
Программа получает целые числа через пробел и выводит количество, сумму, минимум, максимум и среднее с двумя знаками после точки
Пример:
```text
Введите целые числа через пробел: -2 0 5 3
Количество: 4
Сумма: 6
Минимум: -2
Максимум: 5
Среднее: 1.50
```

Дополнительные проверки:
- Ввод `8` - количество 1, сумма 8, минимум 8, максимум 8, среднее 8.00.
- Пустой ввод - `Нет данных`.
- Ввод `0 0` - количество 2, сумма 0, минимум 0, максимум 0, среднее 0.00.

## Задание 2. Независимое преобразование
Файл: `6_2_transform.py`
Программа создаёт новый список, заменяя отрицательные числа их модулями. Исходный список не меняется
Пример:
```text
Введите целые числа через пробел: -2 0 5 -2
Исходный список: [-2, 0, 5, -2]
Новый список: [2, 0, 5, 2]
```

Дополнительные проверки:
- Пустой ввод - оба списка `[]`.
- Ввод `1 2 3` - оба списка `[1, 2, 3]`.
- Ввод `-7 -1` - исходный `[-7, -1]`, новый `[7, 1]`.

## Задание 3. Позиции максимума
Файл: `6_3_positions.py`
Программа находит все индексы максимального числа с помощью `enumerate()`
Пример:
```text
Введите целые числа через пробел: 3 7 2 7
Индексы максимума: [1, 3]
```

Дополнительные проверки:
- Ввод `7 7` - `[0, 1]`.
- Ввод `-3 -1 -2` - `[1]`.
- Пустой ввод - `Нет данных`.

## Задание 4. Индивидуальный вариант 1
Файл: `variant.py`
Программа выбирает чётные числа в исходном порядке, сохраняя повторы, выводит их количество, сумму и новую отсортированную копию
Пример из задания:
```text
Введите целые числа через пробел: -8 -3 0 6 6 1
Чётные числа: [-8, 0, 6, 6]
Количество: 4
Сумма: 4
Отсортированная копия: [-8, 0, 6, 6]
```

Дополнительные проверки:
- Ввод `8 -2 7 4 -6 4` - список `[8, -2, 4, -6, 4]`, количество 5, сумма 8, отсортированная копия `[-6, -2, 4, 4, 8]`.
- Ввод `1 3 5` - список `[]`, количество 0, сумма 0, отсортированная копия `[]`.
- Пустой ввод - список `[]`, количество 0, сумма 0, отсортированная копия `[]`.
- Ввод `0 0 2` - список `[0, 0, 2]`, количество 3, сумма 2.

## Дополнительное задание. Удаление повторов
Файл: `unique.py`
Программа удаляет повторы, оставляя порядок первого появления, без `set`
Пример:
```text
Введите целые числа через пробел: 3 1 3 2 1
Без повторов: [3, 1, 2]
```
Дополнительные проверки:
- Ввод `4 4 4` - `[4]`.
- Пустой ввод - `[]`.
