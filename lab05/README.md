# Лабораторная работа 5. Обработка строк
## Файлы
- `5_1_normalize.py` - удаляет лишние пробельные символы, показывает длины строки и количество слов(регистр сохраняется)
- `5_2_1_palindrome.py` - проверяет палиндром с помощью `[::-1]`(игнорирует только обычные пробелы и регистр)
- `5_3_replace.py` - заменяет все `:` на `-` и считает замены
- `variant.py` - выводит слова на букву 'а' после очистки знаков `.,!?;:` по краям(повторяющиеся слова не удаляются)
- `5_2_1_palindrome_loop.py` - дополнительное задание: палиндром через цикл без обратного среза.
## Проверки
### 1. Нормализация

Ввод: `  Один   два  `
```text
Исходная длина: 14
Новая длина: 8
Нормализованный текст: Один два
Количество слов: 2
```

Ввод: пустая строка.

```text
Исходная длина: 0
Новая длина: 0
Нормализованный текст:
Количество слов: 0
```
Дополнительная проверка: `  ПРИВЕТ   Мир  ` - `ПРИВЕТ Мир`, регистр сохраняется.

### 2. Палиндром
| Ввод | Результат |
| --- | --- |
| `А роза упала на лапу Азора` | `Палиндром` |
| `а    ` | `Палиндром` |
| `     ` | `Нет текста` |
| Пустая строка | `Нет текста` |
| `Python` | `Не палиндром` |
| `А!` | `Не палиндром` |
Знаки препинания и табуляция не удаляются. Сравнение не зависит от регистра.

### 3. Замена
Ввод: `a::b:`

```text
Количество замен: 3
Новая строка: a--b-
```

Ввод: `abc`

```text
Количество замен: 0
Новая строка: abc
```
### 4. Индивидуальный вариант 1
Условие - слово начинается с 'а'.

Ввод: `Анна, армия! Я читаю. Книга, край, рама.`

```text
анна
армия
Количество: 2
```

Ввод: `Анна, анна! АЛЬФА !!!`

```text
анна
анна
альфа
Количество: 3
```

Пустой ввод и `!!!` дают одинаковый результат:

```text
Нет совпадений
Количество: 0
```
### Дополнительное задание
`5_2_2_palindrome_loop.py` сравнивает попарно символы от краёв к середине. Проверяются только `len(cleaned) // 2` пар.
На всех примерах из раздела 'Палиндром' результаты `palindrome.py` и `palindrome_loop.py` совпадают
