# Лабораторная работа №12. Итоговый проект
Вариант 1 — план учебных занятий.
Python 3 (проверено на 3.13.5). Внешние библиотеки не нужны.

## Запуск
```bash
python main.py
```

## Файлы
- `main.py` — меню, ввод и вывод данных.
- `logic.py` — проверка, добавление, поиск, изменение статуса, удаление и статистика.
- `storage.py` — чтение и сохранение JSON.
- `data.json` — три примера учебных занятий.
- `test_logic.py`, `test_storage.py` — автоматические тесты.

## Формат данных
Каждая запись содержит `id` (уникальное положительное целое число), `title` (название), `category` (категория), `amount` (целое количество часов от 0), `completed` (логический статус). Все записи хранятся в списке в JSON с кодировкой UTF-8.

## Пример статистики
Для приложенного файла: всего 3 занятия, выполнено 1, не выполнено 2, всего 9 часов. Математика — 2 часа, программирование — 7 часов.

## Тесты
```bash
python -m unittest -v
```
Все 8 автоматических тестов прошли успешно.

## Результаты приёмки
| Сценарий | Результат |
| --- | --- |
| Файл отсутствует | Пустой список, меню доступно |
| Пустой JSON-список | Статистика равна нулю |
| Две записи на 4 и 2 часа, одна выполнена | Сумма 6, выполнена 1 |
| Пробелы в названии | Удаляются |
| Поиск PY | Находит Python |
| Пустое название, -1, abc | Повторный ввод |
| Неизвестный ID | Данные не меняются |
| Отмена удаления | Запись остаётся |
| Удаление ID 1 и добавление | ID 2 остаётся, новый ID 3 |
| Сохранение и перезапуск | Данные восстанавливаются |
| Повреждённый JSON | Запуск прекращается, файл остаётся прежним |
| Повторный ID | Отклоняется автоматическим тестом |
| Ошибка записи | Проверена в тесте хранения; ветка меню обработана в коде |

Меню проверено запуском с подготовленными последовательностями ввода. Ошибка записи в самом меню вручную не проверялась.
