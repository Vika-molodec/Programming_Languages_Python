## Задание 1. Частоты слов
`word_counts(text)` считает, сколько раз встречается каждое слово. Текст переводится в нижний регистр, знаки `.,!?;:` с краёв слов удаляются.
Примеры:
- `Python, python! SQL` - `{'python': 2, 'sql': 1}`.
- `!!!` - `{}`.
- Пустая строка - `{}`.
`print_word_counts(counts)` выводит слова по алфавиту.

## Задание 2. Учебные интересы
`common_topics(first, second)` находит общие темы, `all_topics(first, second)` - все уникальные темы. Используются множества.
Пример:
- Первый список - `['python', 'sql', 'python']`.
- Второй список - `['sql', 'git']`.
- Общие темы - `['sql']`.
- Все темы - `['git', 'python', 'sql']`.

## Задание 3. Запись и пара
Создаётся словарь `{'title': 'Python', 'hours': 4}`, затем `hours` изменяется на `6` и добавляется `completed: False`.
Кортеж `('Python', 6)` распаковывается в переменные `title` и `hours`.

Словарь удобен для записи, потому что у каждого значения есть понятный ключ. По ключу можно получить или изменить нужное поле, а также добавить новое.

## Вариант 1. Учебные занятия
В программе 6 занятий и 3 категории. `amount` - часы.
- `totals_by_category(records)` - сумма часов по категориям.
- `titles_in_category(records, category)` - названия занятий выбранной категории в исходном порядке.
- `sorted_category_totals(records)` - дополнительное задание: категории по убыванию часов, при равенстве - по названию.
Пример сводки:
```text
гуманитарные: 2
точные науки: 15
языки: 5
```

При вводе `языки` результат: `['Английский язык', 'Русский язык']`.

При вводе неизвестной категории результат: `[]`.

Проверяются обычные и пустые данные, повторы, неизвестная категория, исходный порядок названий, сортировка при равных суммах. Проверено, что исходные словари не изменяются.
