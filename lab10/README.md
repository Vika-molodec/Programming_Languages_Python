# Лабораторная работа №10. Текстовые файлы и обработка ошибок

**Индивидуальный вариант 1:** сумма положительных элементов таблицы.

## Состав файлов
- `main.py` — надёжный ввод положительного целого числа, запуск обработки таблицы, обработка ошибок и запись отчёта.
- `files_lab.py` — функция `read_matrix(path)` для чтения и проверки файла; `selected_sum(matrix)` для варианта 1.
- `table.py` — функции `row_sums(matrix)` и `column_sums(matrix)` для сумм строк и столбцов. Восстановлены для автономной работы, поскольку исходный `table.py` из №9 не был приложен.
- `matrix.txt` — исходная таблица.
- `report.txt` — пример готового отчёта.
- `test_files.py` — автоматические проверки во временной папке.

## Задание 1. Надёжный ввод размера
Функция `read_positive_integer()` повторяет ввод, пока пользователь не введёт целое число больше нуля. Для нецелого числа и для числа меньше либо равного нулю выводятся разные сообщения.
Пример ввода: `abc`, `0`, `-2`, `3`.
Результат: программа сообщает об ошибках первых трёх значений и принимает `3`.

## Задание 2. Чтение таблицы
Формат `matrix.txt`:
```text
2 3
1 -2 3
4 0 -6
```
Первая строка содержит положительные размеры: **2 строки и 3 столбца**. Каждая следующая строка содержит по три целых числа. Пустые и лишние строки запрещены. Обычный перевод строки в конце файла допустим. Файл читается в UTF-8.
`read_matrix(path)` возвращает `[[1, -2, 3], [4, 0, -6]]` или вызывает `ValueError` с пояснением, если содержимое неверно.

## Задание 3. Отчёт
Суммы строк: `2`, `-2`. Суммы столбцов: `5`, `-2`, `-3`.
Содержимое `report.txt`:
```text
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта: 8
```
Для варианта 1 складываются только положительные значения: `1 + 3 + 4 = 8`. Если подходящих значений нет, функция возвращает `0`.

## Запуск
Из папки лабораторной работы:
```bash
python3 main.py
python3 test_files.py
```
При запуске `main.py` сначала введите любое целое число больше нуля. Затем программа прочитает `matrix.txt` и создаст `report.txt` рядом со скриптом.

## Проверки
`test_files.py` проверяет обычную таблицу, таблицу 1×1, пустой файл, нулевой размер, неполную и нечисловую строку, лишние строки, отсутствие файла, правильность сумм и последовательность ввода `abc`, `0`, `-2`, `3`.
**Проверка сохранности отчёта:** во временной папке создан старый `report.txt` с текстом `Старый отчёт`, затем в `matrix.txt` записана ошибка `1 x`. Запуск `create_report()` завершился `ValueError`, а содержимое отчёта осталось прежним. Автоматическая проверка прошла.

## Обработка ошибок
- **Ошибка формата (`ValueError`)** — файл читается, но его данные не соответствуют правилам: например, в таблице вместо числа буква.
- **Ошибка доступа (`OSError`, в частности `FileNotFoundError`)** — проблема открытия или записи файла: путь отсутствует или нет необходимых прав.
- **Ошибка кодировки (`UnicodeError`)** — содержимое файла не удаётся прочитать в UTF-8.
Отчёт открывается на запись **только после успешного чтения и проверки всей таблицы**, чтобы некорректный входной файл не стирал предыдущий отчёт. Исходный `matrix.txt` открывается только для чтения.
