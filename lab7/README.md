# Лабораторная работа 7. Функции и автоматические проверки

Вариант 1 - выбрать числа строго больше порога.

## Файлы
- `functions.py` - функции для вычислений и обработки данных.
- `main.py` - ввод данных и вывод результатов.
- `test_functions.py` - проверки функций с помощью `assert`.

## Пример работы(функции sum_digits, average, normalize_text, select_numbers)
```text
Введите целое число: -507
Сумма цифр: 12

Введите целые числа через пробел: -5 0 2 5
Среднее: 0.5

Введите текст:   ПРИВЕТ   Мир
Нормализованный текст: привет мир

Введите неотрицательный порог: 2
Числа больше порога: [5]
```

Если список чисел пустой, программа выводит `Нет данных`.

## Проверки
- `sum_digits` - ноль, положительное и отрицательное число.
- `average` - пустой список, целое и дробное среднее, неизменность списка.
- `normalize_text` - лишние пробелы, табуляция, перенос строки, пустой текст.
- `select_numbers` - контрольный список, пустой ввод, граница условия, повторы, отсутствие и наличие совпадений, неизменность исходного списка.
- `is_palindrome` - дополнительное задание по правилам работы №5. Регистр и обычные пробелы не учитываются, остальные символы учитываются. Для пустой строки возвращается `False`.
