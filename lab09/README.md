# Лабораторная работа №9. Вложенные списки и таблицы

**Вариант 1 — отрицательные элементы заменить нулями.**

## Файлы

- `table.py` — функции для обработки таблиц.
- `main.py` — ввод таблицы и вывод результатов.
- `test_table.py` — проверки с помощью `assert`.
- `recursion.py` — дополнительное задание про факториал.

## Задание 1. Суммы строк
**Файл:** `table.py` — функция `row_sums(matrix)`.
Функция возвращает список сумм всех строк. Для пустой таблицы возвращает `[]`.
Пример: `[[1, 2, 3], [4, 5, 6]]` → `[6, 15]`.

## Задание 2. Суммы столбцов
**Файл:** `table.py` — функция `column_sums(matrix)`.
Функция проходит по столбцам и складывает значения в каждой строке. Работает с прямоугольными таблицами.
Пример: `[[1, 2, 3], [4, 5, 6]]` → `[5, 7, 9]`.

## Задание 3. Диагональный узор
**Файл:** `table.py` — функция `diagonal_pattern(size)`.
- На главной диагонали — `0`.
- Выше диагонали — `1`.
- Ниже диагонали — `2`.
Пример при размере `3`:
```text
0 1 1
2 0 1
2 2 0
```

## Индивидуальный вариант 1. Преобразование таблицы
**Файл:** `table.py` — функция `transform(matrix)`.
Отрицательные числа заменяются нулями. Остальные значения сохраняются. Функция создаёт новую таблицу и не изменяет исходную.
Пример:
```text
Вход:     [[-2, 0, 3], [4, -5, 6]]
Результат: [[0, 0, 3], [4, 0, 6]]
```

## Запуск
Находясь в папке с файлами, выполните:
```bash
python3 main.py
```
Пример ввода:
```text

Количество столбцов: 3
Строка 1: -2 0 3
Строка 2: 4 -5 6
Размер диагонального узора: 3
```
Основной результат:
```text
Суммы строк: [1, 5]
Суммы столбцов: [2, -5, 9]
Диагональный узор:
0 1 1
2 0 1
2 2 0
Исходная таблица:
-2 0 3
4 -5 6
Преобразованная таблица:
0 0 3
4 0 6
```
Проверки:
```bash
python3 test_table.py
```
Ожидаемый результат: `Все проверки пройдены!`
